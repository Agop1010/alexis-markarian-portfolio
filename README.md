# Portfolio — Alexis Markarian

Première maquette dynamique du site portfolio d’Alexis Markarian.

## Direction visuelle

- fond bleu très clair et grille technique subtile ;
- navigation noire horizontale ;
- grandes surfaces blanches et blocs noirs ponctuels ;
- cartes pastel bleu, vert, crème et lavande ;
- titres premium, accents techniques en IBM Plex Mono ;
- animations discrètes, responsive et prise en charge de `prefers-reduced-motion`.

## Lancer le site dans VS Code

La maquette ne nécessite aucune installation.

1. Ouvrir le dossier dans VS Code.
2. Ouvrir `index.html` avec l’extension Live Server, ou lancer `python -m http.server 8000` dans le terminal.
3. Ouvrir `http://localhost:8000`.

## État de la maquette

Le formulaire fonctionne visuellement mais n’envoie encore aucune donnée. La destination de contact sera connectée uniquement après validation. Les projets présentés sont des concepts de démonstration, à remplacer progressivement par des références réelles.

La feuille de style privilégie `PP Neue Montreal` lorsqu’elle est disponible localement, avec Manrope comme alternative libre. Pour utiliser officiellement PP Neue Montreal, ajouter les fichiers de police couverts par une licence web.
